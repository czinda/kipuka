# Review remediation matrix

Review baseline: `77cd3ae9f398265e7299d1a81da1e973078cc24a`, reviewed 2026-09-05. The finding IDs below correspond to the 38 findings in the original defensive review. This document describes the remediation working tree, not a released version or certification result.

**Implemented** means the identified behavior was changed in code. It does not imply that every backend, device or protocol combination was exercised. **Restricted** means an unsupported setting or operation now fails explicitly. **Scoped exception** means an affected dependency remains with documented reachability analysis and an enforced expiry. Remaining validation is recorded separately; source inspection is not presented as interoperability evidence.

## Additional integration defects found during remediation

- Removed the nonexistent `fullcmc` feature gate and its warning suppression; previously inactive CMC/CMS modules now compile and their routes are mounted.
- Fixed CMS implicit signed-attribute decoding and RSA signature algorithm normalization. Both OpenSSL-generated requests and Kipuka-generated signed responses are verified cryptographically.
- Removed the silent AES-GCM-to-CBC downgrade. GCM responses use CMS AuthEnvelopedData and tampering fails authentication; explicitly requested CBC remains EnvelopedData.
- Fixed STAR named-path extraction so an order ID is not mistaken for an EST label.
- Preserved the CMP request sender's GeneralName encoding as the protected response recipient and required an exact CRL issuer-name match.
